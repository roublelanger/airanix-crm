```bash

  -d '{

      {
        "contact_name": "John Doe",
```

### **Option 4: Using JavaScript/Node**

```javascript
const response = await fetch('/api/contacts/import', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    contacts: [
      {
        contact_name: "Jane Smith",
        email: "jane@example.com",
        company_name: "Tech Inc"
      }
    ]
  })
});

const result = await response.json();
console.log(`Imported: ${result.imported}`);
```

## 📋 CSV FORMAT REQUIREMENTS

**Required column:** Contact Name (or "Name")  
**Optional columns:** Email, Company Name, Phone, Designation, Location, Industry, Remarks, Assigned To

**Good examples:**
```csv
Company Name,Contact Name,Email,Phone,Designation
Acme,John Doe,john@acme.com,555-1234,Manager
Tech,Jane Smith,jane@tech.com,555-5678,Director
```

**Also accepted:**
```csv
Name,Email,Company
John,john@acme.com,Acme
Jane,jane@tech.com,Tech
```

**Edge cases handled:**
- Missing emails (generates temp ones)
- "NA" values (treated as missing)
- No company name (defaults to "Unassigned")
- Extra spaces (auto-trimmed)
- Mixed case (normalized)
